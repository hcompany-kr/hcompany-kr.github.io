打ち合わせは、たいてい同じように終わります。

「この条件でいいですよね」
「はい、それで進めましょう」

契約書はもうあります。けれど本当に大事な条件は、その場で口頭で決まります。納期が前倒しになり、範囲が少し広がり、「これくらいは一緒にやっていただけますよね」が行き交います。

そして仕事が終わるころ、こう言われます。

「これも最初から含まれていませんでしたか」

<p class="pull">口約束も契約です。問題は、それが契約書とぶつかったときです。</p>

## 契約書と違う口頭の合意を13か国はこう扱う

| 国 | 口頭の合意が契約書と違うとき |
|---|---|
| 日本 | 契約に書面は不要（2020年に明文化）。立証は当事者の責任 |
| 韓国 | 契約書の記載どおりに認定。明確で納得できる反証が必要 |
| アメリカ | 完結した契約書なら事前・同時の口頭合意は排除。締結後の変更は別に判断 |
| イギリス | 「変更は書面のみ」条項があれば口頭の変更は効力なし |
| カナダ | 契約書が優先。書面変更条項の効力は裁判所により分かれる |
| オーストラリア | 書面要件があっても、証拠が十分なら口頭の変更を認める |
| ニュージーランド | 書面変更条項は推定にとどまり、強い証拠で覆る |
| インド | 契約書と矛盾する口頭証拠は排除。締結後の変更は立証可（書面・登記が法定の契約を除く） |
| スペイン | 方式自由。不動産物権などは公正証書 |
| メキシコ | 方式自由。法律が方式を定める契約はその方式がなければ無効 |
| チリ | 2UTM超の契約は、締結前・締結時・締結後の発言を証人で立証できない |
| アルゼンチン | 書面にするのが通常の契約は証人だけでは立証できない |
| イタリア | 事前・同時の付加合意は証人不可、締結後の合意は裁判官の裁量 |

調べた国だけを入れています。アイルランドはイギリスの判例に従うかどうかを確認できなかったため外し、ドイツ・フランス・ブラジルも入れていません。

出発点はどの国も同じです。**口約束も契約である。ただし契約書があれば契約書が先に立つ。** 分かれるのはその先です。

## 口約束も契約です

民法522条2項は、法令に特別の定めがある場合を除き、契約の成立には書面の作成その他の方式を具備することを要しないと定めています。2020年4月施行の改正で明文化されたものです。

他の国もほとんど同じです。韓国民法は契約の方式を定めておらず、スペイン民法1278条、メキシコ連邦民法1832条、アルゼンチン民商法典284条も方式の自由を原則にしています。

**例外は法律が決めています。** 日本では保証契約は書面でしなければ効力を生じません（民法446条2項）。ただし電磁的記録によってされた保証契約は書面によってされたものとみなされます（同条3項）。

ここは国によって違います。韓国民法428条の2も保証を書面に限っていますが、**電子的形態で表示された保証の意思は効力がない**と明記しています。イギリスは1677年詐欺防止法4条がいまも保証を書面で証明するよう求めています。

不動産の契約では、イギリスは合意した条件のすべてを一つの書面に入れて双方が署名しなければならず（1989年財産法2条）、イタリアは書面がなければ無効で（民法1350条）、スペインは公正証書によるよう定めています（民法1280条）。

## 契約書があれば、契約書が勝ちます

問題の多くはここで起きます。契約書があるのに、打ち合わせで別のことを口頭で合意した場合です。

**アメリカ・カナダ・オーストラリア**には口頭証拠排除原則（parol evidence rule）があります。契約書が合意のすべてを記録したものと認められれば、それ以前や同時にした口頭の合意で契約書の内容を覆すことはできません。

**インド**はこれを法律に書いています。2023年のBharatiya Sakshya Adhiniyam 95条（旧インド証拠法92条）は、書面契約の内容と矛盾し、変更し、付け加え、削る口頭の合意を証拠として受け付けません。

**韓国**の大法院は、処分文書は真正に成立したと認められれば、その記載内容を否定するだけの明確で納得できる反証がない限り、記載どおりの意思表示があったと認めるべきだとしています（大法院2021年9月30日判決 2019다245457）。

**チリ**はさらに厳格です。民法1709条により、2UTM（税務単位）を超える契約は書面でなければならず、**締結前・締結時・締結後**に言ったとされる内容を証人で立証することはできません。

日本については、調べた範囲では、契約書と異なる口頭の合意を一律に排除する明文の規定は民法に見当たりませんでした。ただ、契約書に書かれていない合意があったと主張する側がそれを立証しなければならない点は同じです。

## 締結後に変えたものは別に扱われます

「これも含まれていたはず」が問題になるのは、たいてい契約書を交わした**あと**です。仕事を進めるうちに範囲が広がるからです。

ここで国が分かれます。

アメリカの口頭証拠排除原則は、契約**後**の変更には適用されません。インドも、契約を解除または変更する**別個の後続の口頭合意**は立証できるとしています。ただし法律が書面を要求する契約や登記された契約は例外です。イタリアは、締結後の合意を証人で立証することを、当事者の性質や契約の性質などから裁判官がもっともらしいと判断した場合に限って認めています（民法2723条）。

チリは前述のとおり、締結**後**の発言も証人では立証できません。

## 「変更は書面によってのみ」と書いてあったら

契約書にはよくこういう一文があります。**「本契約の変更は、両当事者が記名押印した書面によってのみ行う」**

この条項があるとき、口頭で変えた条件が生き残るかどうかは、国によって正反対です。

| 国 | 書面変更条項があるときの口頭の変更 |
|---|---|
| イギリス | 効力なし |
| オーストラリア | 証拠が十分なら認める |
| ニュージーランド | 条項は推定にとどまり、強い証拠で覆る |
| カナダ | 裁判所により分かれ、最高裁の判断なし |
| アメリカ | 一般の契約では厳格に適用されない。物品売買では条項が有効 |
| イタリア | 書面の方式を合意すれば、効力要件と推定 |

**イギリス**最高裁は2018年のRock Advertising v MWB事件で、変更は書面で署名して行うという条項がある契約を口頭で変更しても、契約上の効力はないと判断しました。当事者が本当に変えるつもりだったとしても同じです。

**オーストラリア**は逆です。1906年のLiebe v Molloy判決以来、書面要件があっても、当事者が言葉や行動で別の権利義務に合意したという説得力のある証拠があれば、それを認めてきました。イギリスの判決のあとも、この立場は続いています。

**ニュージーランド**はこの条項を実体的なものではなく証拠上の推定と見ており、強力で説得力のある証拠があれば覆ります。**カナダ**はこの条項を有効とした下級審がある一方、オンタリオ州控訴裁判所はこの条項があるにもかかわらず口頭や行動による変更を認めたことがあり、最高裁の判断はまだありません。

**アメリカ**は一般の契約ではこの条項を厳格には適用しない傾向にありますが、物品売買については統一商事法典2-209条がこの条項を有効としています。**イタリア**は、当事者が将来の契約の方式を書面で合意した場合、その方式を効力要件として望んだものと推定します（民法1352条）。

日本でこの条項の効力を正面から扱った最高裁判例は確認できていません。

## フリーランス取引なら、法律が書面を求めています

2024年11月に施行されたフリーランス法の第3条は、発注者に対し、業務委託をした場合に直ちに取引条件を書面または電磁的方法で明示するよう義務づけています。内容が定められないことに正当な理由がある事項も、定まった後直ちに明示しなければなりません。

詳しくは[口頭での発注は、いま法律で禁止されています](https://hcompany-kr.github.io/blog/ja/freelance-payment/)にまとめています。

## 結局、打ち合わせで何を言ったかを示せるかどうかです

13か国のどこでも、**口約束は有効だが、契約書と違うならそれを主張する側が立証する**。そしてその立証は、ほとんどが打ち合わせで何が話されたかに集まります。

現実的な方法は二つです。

**打ち合わせが終わったら、その日のうちにメールやメッセージでまとめて送る。**「本日のお打ち合わせのとおり、○○まで含めて進めます」。相手から返信がなくても、その日そう理解していたという記録が残ります。

**打ち合わせを録音する。** 日本には、自分が参加している会話の録音を処罰する法律はありません（[日本には「盗聴罪」がありません](https://hcompany-kr.github.io/blog/ja/recording-consent-law/)）。ただ、受注する側から「録音してもいいですか」とは言い出しにくいのが現実です。

TalkSafeは、あらかじめ決めた言葉が聞こえると録音を始めるAndroidの録音アプリです。画面がロックされた状態でも動作し、録音が始まる前の30秒もあわせて保存します。端末を取り出して操作し、打ち合わせの流れを止める必要がありません。

録音を証拠として使うとき、原本と冒頭がなぜ大事かは[録音はあるのに、証拠として使えないとき](https://hcompany-kr.github.io/blog/ja/recording-evidence/)にあります。

## まとめ

- 口約束も契約です。ただし保証のように書面が必要な契約があります。
- 契約書があれば契約書が先です。違う合意を主張する側が立証します。
- 締結後に口頭で変えた条件は国によって扱いが違います。「変更は書面のみ」条項は、イギリスでは強く、オーストラリアでは弱い。
- 打ち合わせで決めたことは、その日のうちにメッセージで残すか、録音しておきます。

お金を口約束だけで貸した場合の、13か国の時効と承認の扱いは[借用書なしで貸したお金](https://hcompany-kr.github.io/blog/ja/lent-money/)にまとめています。
